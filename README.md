# apt-reports

단지 분석 & 임장 가이드 리포트 모음. 국토부 실거래 1차 데이터 + 다출처 교차검증 기반.

🔗 https://aboutbit.github.io/apt-reports/

## 작성 원칙

- 1차 데이터(국토부 실거래) + 다출처 일치 정보만 게재
- 추정·일반화 정보는 의도적으로 제거
- 검증 못 한 항목은 "현장에서 확인할 것" 으로 명시
